About This Project

Community Disaster Preparedness and Emergency Information System

Emergency Hotline: 112

Project Objective

To create a digital platform that helps communities access disaster preparedness information, emergency contacts, safety guidelines, and emergency resources in one place.

Problem Statement

During disasters, people often struggle to find reliable, organized information quickly — scattered contact numbers, unclear safety steps, and no single place to check alerts or report an emergency. This gap costs valuable time when it matters most.

Proposed Solution

A single, easy-to-navigate website that brings together emergency alerts, preparedness guides, verified contact numbers, nearby resources, and a simple way to report an incident — usable on any device, even with a basic internet connection.

Key Features

  • Real-time-style emergency alerts with severity levels and filters
  • Disaster preparedness guides for flood, earthquake, fire, cyclone, and landslide
  • One-tap emergency contact calling
  • Map-based emergency resource finder
  • Emergency reporting form with a trackable Report ID
  • Interactive emergency kit checklist
  • Admin demo panel for managing community reports

Target Users

Residents of a community or neighborhood, local disaster management volunteers, and community organizers who need quick access to preparedness information during normal times and emergencies alike.

Technology Used

HTML, CSS, and JavaScript for the frontend; Tailwind-style utility patterns and custom CSS for styling; Leaflet.js with OpenStreetMap for maps; Font Awesome for icons; and browser LocalStorage for saving reports, contacts, and checklist progress without needing a server.

Future Enhancements

  • Real-time weather alerts
  • Government disaster alert API integration
  • GPS-based nearby emergency resource detection
  • SMS notifications
  • User authentication
  • Cloud database (Firebase or Supabase)
  • AI-based disaster information assistant
  • Multi-language support, including Kannada and English
